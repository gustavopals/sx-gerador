# Suporte e canais de feedback

## Onde tirar dúvida ou reportar problema

| Situação                        | Canal                                                                                                                                          |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 🐛 Encontrei um bug             | [GitHub Issues — Bug](https://github.com/sxgerador/sxgerador/issues/new?template=bug_report.yml)                                               |
| ✨ Tenho uma ideia de feature   | [GitHub Issues — Feature](https://github.com/sxgerador/sxgerador/issues/new?template=feature_request.yml)                                      |
| 🤔 Tenho uma dúvida             | [GitHub Issues — Pergunta](https://github.com/sxgerador/sxgerador/issues/new?template=question.yml) ou [Discord](https://discord.gg/sxgerador) |
| 💬 Quero papo da comunidade     | [Discord](https://discord.gg/sxgerador) (em construção)                                                                                        |
| 🔒 Vulnerabilidade de segurança | [Security advisory privado](https://github.com/sxgerador/sxgerador/security/advisories/new) ou security@sxgerador.com.br                       |
| 📨 Imprensa / parcerias         | hello@sxgerador.com.br                                                                                                                         |

## Antes de abrir um issue

1. Consulte a [documentação](https://docs.sxgerador.com.br) e o [FAQ](https://docs.sxgerador.com.br/faq/).
2. Pesquise se já existe um [issue parecido](https://github.com/sxgerador/sxgerador/issues?q=).
3. Use o template adequado e preencha o máximo de detalhes — economiza idas e voltas.

## SLA de resposta

O projeto é mantido pela comunidade. Em dias úteis tentamos responder em **até 48 horas**, mas não há SLA formal — exceto para vulnerabilidades de segurança, que têm prioridade máxima.
