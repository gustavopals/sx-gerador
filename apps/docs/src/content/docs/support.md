## Canais

### 🐛 GitHub Issues (principal)

Para **bugs, features e perguntas técnicas**:
[github.com/sxgerador/sxgerador/issues](https://github.com/sxgerador/sxgerador/issues/new/choose)

Tempo médio de resposta: 48h em dias úteis.

### 💬 Discord

Bate-papo da comunidade, ajuda rápida, anúncios:
[discord.gg/sxgerador](https://discord.gg/sxgerador) _(em construção — primeiros usuários serão convidados)_

### 📨 Email

Para **assuntos sensíveis** (vulnerabilidades, parcerias, imprensa):
[hello@sxgerador.com.br](mailto:hello@sxgerador.com.br)

### 🔒 Segurança

Vulnerabilidades **não** devem ir para Issues público. Mande para [security@sxgerador.com.br](mailto:security@sxgerador.com.br) ou abra um [security advisory privado](https://github.com/sxgerador/sxgerador/security/advisories/new).

Veja a [política de segurança completa](https://github.com/sxgerador/sxgerador/blob/main/SECURITY.md).

## O que escolher?

| Situação                            | Canal                                        |
| ----------------------------------- | -------------------------------------------- |
| Encontrei um bug                    | GitHub Issues (template Bug)                 |
| Tenho uma ideia de feature          | GitHub Issues (template Feature)             |
| Tenho uma dúvida de uso             | GitHub Issues (template Pergunta) ou Discord |
| Quero conversar com outros usuários | Discord                                      |
| Encontrei uma vulnerabilidade       | Email security@ ou advisory privado          |
| Quero falar com o time              | hello@sxgerador.com.br                       |
